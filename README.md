# パックマンゲームの遊び方

このゲームは、特別な環境構築を必要とせずに簡単に遊ぶことができます。

## 1. 一番簡単な方法
1. このプロジェクトのフォルダをダウンロードまたはクローンします。
2. フォルダ内にある `index.html` ファイルをダブルクリックします。
3. お使いのブラウザ（Chrome、Edge、Firefoxなど）でゲームが起動します。

## 2. おすすめの方法（VS Codeを使用する場合）
開発者として少し本格的に動かしたい場合は、以下の方法がおすすめです。
1. **VS Code**（Visual Studio Code）をインストールします。
2. VS Codeの拡張機能（Extensions）から **"Live Server"** を検索してインストールします。
3. `index.html` を開き、右下の **"Go Live"** ボタンを押します。
   - これにより、ファイルを保存するたびに自動でブラウザが更新されるようになります。

## 操作方法
- **矢印キー (↑ ↓ ← →)**: パックマンを動かす
- 全てのエサ（白い点）を食べるとクリアです。
- 幽霊に当たるとゲームオーバーです。

## ファイル構成
- `index.html`: ゲームの画面構成
- `style.css`: ゲームのデザイン（見た目）
- `game.js`: ゲームの動き（プログラムの本体）
